# 🌾 FarmSense – Crop Cost & Profit Analyzer

A Python-based application to analyze crop costs, farming expenses, revenue, and profit or loss.

## 📌 About the Project

FarmSense helps users maintain crop records and understand the financial performance of different crops. It calculates total farming costs, revenue, profit or loss, profit percentage, and cost per quintal.

The application uses Python for processing, CSV files for storing crop records, and NumPy and Pandas for data analysis.

## ✨ Features

- **Add Crop Record:** Store crop details and farming expenses.
- **View All Crop Records:** Display saved crop information.
- **Search Crop:** Find a particular crop record.
- **Update Crop Record:** Modify existing crop details.
- **Delete Crop Record:** Remove a crop record.
- **Profit Analysis:** Calculate revenue, expenses, and profit or loss.
- **Expense Analysis:** Analyze different farming expenses.
- **Crop Comparison:** Compare the financial performance of crops.
- **NumPy Analysis:** Perform numerical analysis.
- **Pandas Data Analysis:** Analyze crop records in tabular form.
- **Generate Farm Report:** Generate a summary of stored crop records.

## 🧮 Calculations

- **Total Cost** = Sum of all farming expenses
- **Revenue** = Production × Selling Price per Quintal
- **Profit or Loss** = Revenue − Total Cost
- **Profit Percentage** = (Profit ÷ Total Cost) × 100
- **Cost per Quintal** = Total Cost ÷ Production
